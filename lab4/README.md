### 1.1 Q1：链表基本操作

封装链表类 `LinkedList` 与链表迭代器类 `Iterator`，实现以下操作：

| 操作码 | 操作 | 说明 |
|---|---|---|
| 1 | `insert(idx, val)` | 在 0-indexed 的 `idx` 处插入元素 `val` |
| 2 | `remove(val)` | 删除第一个值为 `val` 的节点；若不存在则输出 `-1` |
| 3 | `reverse()` | 原地逆置整个链表，空间复杂度 O(1) |
| 4 | `indexOf(val)` | 查询元素 `val` 的索引（0-indexed，输出第一个匹配项）；不存在输出 `-1` |
| 5 | `output()` | 基于迭代器遍历链表，输出异或累加和 `f = Σ(i ⊕ chain[i])` |

## 二、数据结构与算法描述

### 2.1 数据结构设计

**（1）链表节点 `listNode`**

```cpp
struct listNode {
    int data;        // 数据域
    listNode* next;  // 指针域，指向后继节点
    listNode(int d = 0, listNode* n = nullptr) : data(d), next(n) {}
};
```

**（2）链表类 `LinkedList`**

采用**带头结点（哑节点）**的单链表结构，成员包括：

- `head`：指向头结点的指针（头结点不存数据，其 `next` 指向第一个数据节点）；
- `tail`：尾节点指针（Q2 中维护，使尾插操作降为 O(1)）；
- `size`：当前链表长度。

带头结点的设计使**空表与非空表的插入/删除逻辑完全统一**：插入时只需定位前驱、修改前驱的 `next`；删除时只需前驱的 `next` 绕过被删节点，无需对"删除第一个节点"做特判。

**（3）迭代器类 `Iterator` / `LinkedListIterator`**

```cpp
class LinkedListIterator {
private:
    listNode* ptr;
    LinkedListIterator(listNode* p) : ptr(p) {}   // 私有构造
public:
    int& operator*() const { return ptr->data; }   // 解引用取元素
    LinkedListIterator& operator++();              // 前移
    LinkedListIterator operator++(int);            // 后移（后置）
    bool operator==(...) / operator!=(...);
    friend class LinkedList;                        // 仅链表类可创建迭代器
};
```

迭代器内部仅持有一个节点指针，重载 `*`、`++`、`==`、`!=` 后即可像 STL 迭代器一样用 `for (it = begin(); it != end(); ++it)` 遍历。构造函数设为私有并通过 `friend` 授权给 `LinkedList`，保证迭代器只能由链表类经 `begin()`/`end()` 产生，不会被外部随意构造，体现了良好的封装性。

### 2.2 核心算法描述

**（1）指定位置插入（Q1/Q2）**

从 `head` 出发走 `idx` 步找到第 `idx-1` 个节点（即待插入位置的前驱），在其后链接新节点；越界索引夹取到 `[0, size]`。时间复杂度 O(n)。

**（2）删除第一个指定值节点（Q1/Q2）**

用前驱指针 `p` 扫描，比较 `p->next->data` 与目标值，命中后 `p->next = p->next->next` 并 `delete` 被删节点；扫描完未命中则输出 `-1`。时间复杂度 O(n)。

**（3）原地逆置（Q1/Q2）**

经典三指针迭代法：维护 `prev`、`cur`、`nxt` 三个指针，每次令 `cur->next` 反指 `prev` 后整体前移，最后把头结点的 `next` 指向新的首节点。仅使用常量个辅助指针，**额外空间 O(1)**，时间 O(n)。

**（4）异或累加和（Q1/Q2）**

用迭代器遍历：`sum += i ^ (*it)`，累加器采用 `long long` 防止溢出。时间复杂度 O(n)。

**（5）无序序列 → 有序链表（Q2）**

采用**插入排序思想**：读入每个元素后调用 `insertSorted(val)`，从表头扫描到第一个 `data >= val` 的节点之前插入。建表完成即得到升序链表。时间复杂度 O(n²)（数据规模较小时足够，且天然保持"小于者在前、相等者按读入顺序"的稳定次序）。

**（6）有序链表合并（Q2，基于迭代器）**

两路归并：用两个迭代器 `it1`、`it2` 分别从头遍历两个有序链表，比较 `*it1` 与 `*it2`，把较小者 `push_back` 到结果链表并前进对应迭代器（相等时取 `it1`，保证稳定性）；一方耗尽后把另一方剩余元素依次接入。比较与取值全程通过迭代器完成。时间复杂度 O(n+m)，其中 n、m 为两链表长度。

### 2.3 复杂度汇总

| 操作 | 时间复杂度 | 额外空间 |
|---|---|---|
| 指定位置插入 | O(n) | O(1) |
| 删除指定值节点 | O(n) | O(1) |
| 原地逆置 | O(n) | O(1) |
| 异或累加和 / 打印 | O(n) | O(1) |
| 建有序链表（插入排序） | O(n²) | O(1) |
| 迭代器归并合并 | O(n+m) | O(1)（新链表占用外） |

## 四、分析和探讨

**1. 带头结点（哑节点）的价值**

实验中统一采用带头结点的结构。若不带头结点，删除首节点、向索引 0 插入都需要修改头指针本身，函数需用二级指针或返回新头，代码分支增多。带头结点后，`head` 永远不变，所有插入/删除都归结为"修改前驱的 `next`"，代码显著简化，这是链表实现中最实用的技巧之一。

**2. 尾指针的维护成本与收益（Q2）**

Q2 增加了 `tail` 成员使 `push_back` 从 O(n) 降为 O(1)。但代价是 `insert`、`insertSorted`、`remove`、`reverse` 等所有可能改变尾部的操作都必须同步更新 `tail`，遗漏任何一处都会产生隐蔽 bug（例如逆置后若忘记把原头节点设为新尾，后续尾插会接错位置）。实验中逆置函数里专门处理了 `tail = (oldFirst == nullptr) ? head : oldFirst` 这一细节。这种"冗余状态一致性"的维护，正是数据结构课程强调的重点。

**3. 迭代器的封装设计**

迭代器构造函数设为私有并 `friend` 授权给链表类，用户只能通过 `begin()`/`end()` 获得迭代器。这样既复用了 STL 风格的范围 for 遍历语法，又避免了外部构造悬挂迭代器。解引用返回 `int&`，使得 `*it` 既可用于读取（异或和、合并比较）也可用于修改，接口简洁统一。

**4. 建有序链表为何用插入排序**

Q2 要求将无序序列转化为有序链表且禁用 STL 排序。插入排序与链表天然契合：数组上插入排序需要搬移元素，而链表只需修改指针，无元素搬移开销；且算法实现只需一个 `insertSorted` 原语。其 O(n²) 复杂度在课程数据规模下完全够用。若数据规模更大，可改用链表版归并排序（O(n log n)），这也是可进一步优化的方向。

**5. 合并策略的选择：复制式 vs 破坏式**

本实验的 `mergeSorted` 采用**复制式合并**——通过迭代器读取两个链表的元素值，新建节点尾插到结果链表。优点是原链表保持不变、可以复用，且完全符合"用迭代器实现合并"的要求。另一种思路是**破坏式合并**（把两个链表的节点拆下重组，不新建节点），空间更省，但需要直接操作节点指针，迭代器无法胜任，故未采用。若题目强调 O(1) 空间合并，则需要让迭代器暴露节点指针或改用节点级接口。

**6. 逆置的空间复杂度**

逆置使用三指针迭代而非递归或辅助数组，额外空间严格为 O(1)。注意递归写法（如递归逆置）虽然代码短，但函数调用栈会占用 O(n) 空间，不满足题目 O(1) 要求，故采用迭代实现。

**7. 遇到的问题与解决**

- **问题 1**：最初把迭代器类名写作 `Iterator`，与 Q2 要求的 `LinkedListIterator` 不符——通过重命名并统一两题的接口解决；
- **问题 2**：调试阶段希望观察每次操作后的链表状态，为 `LinkedList` 增加了 `print()` 遍历打印接口（基于迭代器实现），调试完成后在提交版中注释掉相关调用，避免污染 OJ 输出格式；
- **问题 3**：异或累加和在极端数据下可能超出 `int` 范围，累加器改用 `long long` 保证安全。

**8. 总结**

通过本实验，完整实践了链表类与迭代器类的封装、带头结点单链表的各类基本操作、O(1) 空间原地逆置、插入排序建表以及基于迭代器的两路归并合并，加深了对链表结构"改指针而非搬元素"这一本质特性的理解。
